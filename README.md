# 行测自习室

免费的个人行测练习网页，支持专项、整卷、自动判题、错题、收藏、备份和当前题组离线保存。

题库来源：[ERRRC/xingcezhenti](https://github.com/ERRRC/xingcezhenti)，固定源版本 `278984401124db40da5163a31275b8deb9c282f4`。每次构建验证全部 257 个题目数据文件与已测试版本的 SHA-256，一致后才部署。共 28,005 道题目版本，111 道缺少有效标准答案而仅供阅读，原库缺 2 张公式图。

## 使用

网页：https://xushengxr.github.io/Webpage-for-Practicing-Civil-Service-Exam/

首次发布成功后该网址才可用。iPhone 用 Safari 打开 → 分享 → 添加到主屏幕。固定从主屏幕图标进入，联网开始一组题后保存当前题组，等完成后可断网继续。未保存的其他题组仍需网络。

学习记录保存在本机浏览器，不上传；请定期导出备份，更换入口/设备后手动导入。浏览器清理数据或空间不足可能移除缓存和记录。

## 部署

在仓库 Settings → Pages 中将 Source 选为 GitHub Actions。推送 main 后，工作流会从固定版本重建完整题库并部署。仅使用静态 Pages，无微信云套餐，无付费数据库。网页代码、题库和图片公开；仓库不含私人备份、微信 AppID、云环境配置或密钥。

不要在此仓库提交个人学习备份。iPhone Safari 真机离线效果需首次发布后实测，电脑模拟验证不能代替真机。
